# Dashboard Lex Capital (réplica UI)

Implementado en **Angular + Tailwind** (stack del monorepo; el prompt pedía Next.js/React).

## Ver

1. Login → http://localhost:4200/login  
2. Tras entrar aterrizas en `/dashboard`

## Componentes

- `Sidebar` + `Header` (`core/layout/shell`)
- `KpiCard`, `DonutChart`, `StageBarChart`, `TaskList`
- `RecentCasesTable`, `AdvisorPerformanceTable`
- Mock data en `features/dashboard/mock-data.ts`
